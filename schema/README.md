# Формальная проверка XML jewTeX

**Канонические тексты остаются в существующих XML**, переводов и цитат здесь нет.

- `jewtex.rng` — [RELAX NG](https://relaxng.org/) (XML syntax). Базовый *переходный* контракт: все существующие имена элементов и атрибуты допускаются для обратной совместимости; **новые блоки `semantic_data version="1"` проверяются структурно и типизированно**. Это **ещё не исчерпывающая строгая схема всех старых тегов**.
- `../tools/xml_audit.py` — семантический контроль связности произвольных цепочек передачи, повторов `xml:id`, корректности статусов; инвентаризация реальных элементов/атрибутов и редакторских кандидатов без автоматического изменения переводов.
- `../tools/test_xml_schema.py` — регрессионные примеры правильной и неправильной цепочки.
- В CI на каждый PR/push запускаются обычная XML-валидация, RELAX NG, аудит и тестовые примеры. Отчёт `xml-audit.json` публикуется как артефакт GitHub Actions; сводка — в summary run.
- Будущий `element-inventory.json` — **контроль эволюции тегов**: новые элементы потребуют обновить описание схемы и инвентарь одновременно. Идентификаторы `idx` для Sefaria **не** считаются уникальными XML ID.

## Цепочки передачи

Вложенный `semantic_data` содержит `transmission`, любое положительное число упорядоченных `relay` и конечный `attributed_to`. Каждое звено от A к B проверяется отдельно; атрибуция авторства конечному участнику помечается как **передаваемая**, а не как автоматически доказанное мнение говорящего. Программный валидатор проверяет непрерывность всех звеньев и запрещает агрегатный `verified`, когда хотя бы одно звено не проверено.

**Запрет на преждевременное внедрение:** текущая версия XSLT jewTeX пока не тестировалась на новых `semantic_data` и `transmission` внутри книжных XML; **не публиковать такие блоки в текстах**, пока не появится тест на скрытие служебной разметки и отсутствие изменения цитат. Сама схема уже может быть опубликована и проверена без добавления нового текста. Действующие `<p-ai>`, `<work_needed>`, `<quote>` не меняются.

Соблюдать редакционный протокол `Ishayahu/main-ai/links/JEWTEX-TEXTS-MARKUP.md`.

## Контроль изменения набора тегов

`schema/element-inventory.json` содержит реальный список 84 имён элементов (включая SVG с пространством имён) на основе полного прогона по 1618 XML-файлам 06.11.2026. В CI новые **неописанные имена элементов** вызывают ошибку и требуют осознанно обновить инвентарь после проверки совместимости со XSLT и парсером. Новые атрибуты старых элементов пока допускаются в переходной схеме; для строго типизированного `semantic_data` они запрещены, если не указаны в RELAX NG. Не объявлять эту переходную схему исчерпывающей моделью всех существующих элементов.

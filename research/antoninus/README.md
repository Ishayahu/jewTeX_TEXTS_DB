# Каталог упоминаний Антонинуса

Этот каталог — воспроизводимый результат систематического поиска по текстовому индексу Sefaria. Он не утверждает, что все носители имени `אנטונינוס` — один человек или Антонин Пий.

## Файлы

- `registry.json` — основной машиночитаемый реестр: устойчивый ID, книга, точный адрес, прямая ссылка, полный проверочный фрагмент до 700 знаков, написание имени, классификация, параллельный сюжет, статус атрибуции и наличие перевода в базе.
- `search_sefaria.py` — пагинированная выгрузка Search API v2.
- `build_registry.py` — дедупликация версий, фильтрация технических совпадений, классификация и построение реестра.

## Метод

Поиск выполнен по 18 написаниям имени: `אנטונינוס`, `אנטונוס`, `אנטולינוס`, `אנטלימוס`, `אנטוניוס`, `אנטונין`, `אנטולימוס`, `אנטינוס`, `אנטינינוס`, `אנטונינס`, `אנטנינוס`, `אנטוניניס`, `אנטינינס`, `אנטולינס`, `Antoninus`, `Antoninos`, `Antonios`, `Antolinus`. Для каждого написания использованы поля `exact` и `naive_lemmatizer`; все страницы выгружены блоками по 100 результатов. Пользовательские листы Sefaria не включались.

Каждая запись `verified=true` основана на полном индексированном сегменте, возвращённом Search API, а не только на заголовке выдачи. Разные версии одного Sefaria `ref` сведены в одну запись, но перечислены в `sefaria_versions`. Разные адреса и редакции не объединены. Технические совпадения (например, шифр рукописи «Antonin 236») вынесены в `excluded_false_positives`.

Классификация относится к фрагментам, а не к числу независимых исторических событий. Например, несколько сегментов одной сугьи считаются несколькими адресуемыми фрагментами, но связываются одним `parallel_group`.

## Ограничения полноты

1. Полнота доказана только относительно доступного текстового индекса Sefaria на момент выгрузки, перечисленных написаний и двух поисковых полей.
2. Тексты, отсутствующие в Sefaria или не распознанные OCR/индексом, требуют отдельного поиска. В частности, остаются проверки «Ливнат а-Сапир», возможного самостоятельного места в Зоаре и внешних библиотек.
3. `naive_lemmatizer` даёт шум; он отфильтрован по наличию принятого написания в полном индексированном сегменте, но историческая идентификация носителя имени часто остаётся неопределённой.
4. Поле `database_status=translated` означает наличие соответствующего адресуемого русского текста в этой базе; оно не означает независимой вычитки перевода.
5. Позднее цитирование не считается новым первичным свидетельством даже тогда, когда поисковая выдача возвращает его отдельным результатом.

## Воспроизведение

```bash
python3 research/antoninus/search_sefaria.py --output /tmp/antoninus-sefaria-raw.json
python3 research/antoninus/build_registry.py /tmp/antoninus-sefaria-raw.json research/antoninus/registry.json
```

Сырые 6,6 МБ результатов намеренно не коммитятся: все необходимые для аудита тексты и метаданные сохранены в `registry.json`, а исходную выдачу можно воспроизвести скриптом.
